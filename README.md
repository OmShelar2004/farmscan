# 🌱 FarmScan AI

AI-powered mobile crop disease detection and farmer advisory assistant.

## 🚀 Features

- 📸 Tomato & Potato leaf disease detection
- 🤖 Gemini-powered AI farming chatbot
- 📱 React Native (Expo) mobile app
- 🔥 Flask backend with ML integration

## 🛠 Tech Stack

- React Native (Expo)
- Flask
- TensorFlow / Keras
- Google Gemini API

## 📦 Setup Instructions

### Backend
cd backend  
pip install -r requirements.txt  
python app.py  

### Frontend
npm install  
npx expo start  

> Note: Dataset and model (.h5) files are excluded due to GitHub size limits.
